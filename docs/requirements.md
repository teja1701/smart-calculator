C2.1) Functional Requirements :
    1. User should be able to enter their monthly income.
    2. User should be able to enter the loan amount they need.
    3. User should be able to check their loan eligibility.
    4. System should display whether the user is eligible or not.
    5. System should show the reason.

C2.2) Non-Functional Requirements :
    1. The result should be shown quickly.
    2. User information should be kept secure.
    3. The application should be easy to use.

C2.3) No knowledge about processing loan payments.
