PROBLEM STATEMENT : To build a smart calculator.

WHY smart-calculator??
1. to solve the problems users face while performing manual calculations.
2. to reduce the time required to perform calculations.
3. to minimize human errors.
4. to support both basic and scientific calculations.

What difficulties are we facing?
1. Manual calculations take more time especially involving large numbers or multiple operations.
2. Existing basic calculators do not support advanced scientific operations.
3. After clearing the calculator, users cannot see their previous calculations so they need to perform them again where time gets wasted.
4. Similarly, when we press AC (all clear) button accidentally, we have to restart from beginning.
5. Invalid mathematical operations, such as division by zero or incorrect expressions, can confuse users if proper error messages are not displayed.

proposed solution :
1. make sure results are accurate and fast.
2. should support both basic and scientific mathematical operations.
3. make sure there is a history feature to store previous calculations.
4. must provide an Undo option or confirmation before clearing.
5. ensure inputs are valid and display meaningful error messages.

FUNCTIONAL REQUIREMENTS :
1.user should be able to enter numbers and mathematical operators.
2.should be able to perform both basic and scientific mathematical operations.
3.should display the result after each calculation.
4.must display an appropriate error message for invalid inputs or operations.
5.history feature to store previous calculations.

NON - FUNCTIONAL REQUIREMENTS :
1.should respond quickly to user inputs.
2.application should be available 24/7.
