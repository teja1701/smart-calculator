B2.1) 1.validate - checks whether the project is correct.
      2.compile - compiles the Java code.
      3.test - runs the test cases.
      4.package - helps in creating the JAR file.

B2.2) mvn package creates the JAR file and mvn install also does the same and saves it in the local Maven repository.
