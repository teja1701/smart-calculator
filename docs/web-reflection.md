# Web Reflection

## 1. DevTools observation

When the page is opened, the browser sends HTTP requests for the HTML and CSS files.
The browser then uses them to build and display the page.

## 2. CLI vs Web Calculator

The CLI calculator takes input directly from the terminal and prints the result.
The web calculator collects input through buttons and displays it on a web page.

## 3. Where JavaScript is needed

JavaScript would be needed to make the calculator buttons respond to clicks,
perform calculations, and update the display.
